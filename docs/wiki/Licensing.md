## 中文

### 1. 这不是 OSI Open Source

EmbedPluginUI 公开源代码，但限制商业使用，因此应描述为：

> **Source-Available / 源码可见，非商业免费，商业双授权。**

不要把它称为 MIT/Apache/BSD 意义上的“开源软件”。OSI Open Source 要求许可证不能限制商业领域使用，而本项目明确要求商业使用事前获得授权。

### 2. 公共非商业许可证

仓库根目录 `LICENSE` 为 **EmbedPluginUI Non-Commercial Source License 1.0**。

在遵守许可证的前提下，允许个人和非商业用途：

- 个人学习；
- hobby / DIY；
- 学术学习和非商业研究；
- 个人实验与评估；
- 非营利公开演示；
- 修改源码用于上述用途；
- 以同样非商业许可证分享修改版本，并保留版权/授权声明。

### 3. 什么情况需要商业授权？

以下情况在开始之前必须获得单独书面商业授权，包括但不限于：

- 将 EmbedPluginUI 集成到销售/租赁/收费提供的硬件产品；
- MCU/OLED UI 随商业设备固件出货；
- 把框架或其修改版本作为商业 SDK、软件、服务的一部分；
- 为客户交付包含该框架的付费项目；
- SaaS/云服务/付费服务的生产系统中使用；
- 营利性公司的内部生产业务系统中使用；
- OEM/ODM 产品、批量设备、车载/机器人/工业设备商业部署；
- 通过该软件直接或间接获得商业利益。

不确定是否属于商业使用时，应在部署前联系授权方。

### 4. “不能上车后补票”

本项目商业授权采用明确的 **prior authorization** 原则：

> 商业许可证必须在商业使用开始之前签署/获得。

后续购买商业许可证**默认不追溯授权**此前已经发生的无授权商业使用。只有 Licensor 在书面商业协议里明确写出 retroactive authorization / waiver 时，才可能覆盖此前行为。

公共非商业许可证的权利在发生超范围商业使用时按许可证约定终止；不存在自动的“先商用，之后补钱就自动合法化”的权利。

EmbedPluginUI publishes source code but restricts commercial use. The correct description is:

> **Source-available, free for permitted non-commercial use, commercially dual-licensed.**

It should not be described as MIT/Apache/BSD-style Open Source because the public license restricts commercial use.

The root `LICENSE` is the **EmbedPluginUI Non-Commercial Source License 1.0**. Subject to its terms, it permits personal study, hobby use, academic/non-commercial research, experimentation, evaluation, modification for those purposes, and non-commercial redistribution under the same terms with notices preserved.

### 3. Commercial license required

A separate written commercial license is required before use in revenue-generating or for-profit activity, including shipping the library in paid hardware/firmware, commercial SDKs/software/services, paid client deliverables, production use by a for-profit business, OEM/ODM deployments, or other direct/indirect commercial advantage.

### 4. Prior authorization — no automatic “pay later” cure

The commercial license must be obtained **before commercial use begins**. A later commercial license does not automatically retroactively authorize earlier unlicensed commercial use. Retroactive authorization or waiver exists only if the Licensor expressly grants it in writing.
